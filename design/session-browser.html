The agent drives loopback pages in the same tabs.

8 · Terminals dock: what a first-time user sees

One bar of icons. It names the selected process with its state dot (the state in words only after it ended), then New terminal (+), a chevron for scripts and the folder new terminals run in (only when the folder lists scripts or the Session has another folder), Split, Restart, Stop while it runs or Remove once it ended, Maximize and Hide (processes keep running). From the second process on a list at the right shows each with its state dot; Split rows are joined by tree lines. Tooltips carry the command and the folder. Below 384 px the word Terminals drops.
