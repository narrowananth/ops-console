Pull request page, Bitbucket style

Review sheet for the change set: one Session per pull request, Sessions and Pull requests as two sidebar pages, a threaded Activity with the code each comment is on, a Files changed tab with file tree, Comments and Sort menus and no right rail, and the two agent buttons on every thread. Names, repos and text are placeholders. Dashed outline marks what is new.

1. Sidebar: Sessions and Pull requests are two pages

The Sessions / Pull requests switch inside Workspace goes. The app sidebar gets two items in Operate where Workspace was, each with its own list on the left and the same detail on the right. The Permissions item goes too (Connect group). The red badge on Sessions counts the ones that need you, as the folded strip's does today.

2. Overview: Activity as threads with their code

Each comment thread is one card: file and line on top, the code lines it is on (the diff hunk, the line marked), then the comments in order, then the actions. General comments have no code block. Events (pushed a commit, edited the description, agent review) sit between the threads in time order with the day as a divider. The rail stays here.

3. Files changed: tree, Comments menu, Sort, and no rail
